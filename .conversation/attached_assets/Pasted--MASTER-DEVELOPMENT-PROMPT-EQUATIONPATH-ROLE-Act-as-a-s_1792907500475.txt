# 5. MODULE ONE — EQUATION SOLVER

Support first-order differential equations in the form:

M(x,y) dx + N(x,y) dy = 0

Provide two independent mathematical input fields:

M(x,y): [input]
N(x,y): [input]

Example:
M = 2*x*y + 3
N = x**2 + 4*y

Input requirements:
- Accept standard SymPy-compatible mathematical expressions.
- Support powers, fractions, polynomials, trigonometric functions, exponentials, and logarithms where mathematically supported.
- Provide controlled and safe parsing with explicitly permitted symbols and functions.
- Never evaluate arbitrary Python code.
- Display a live rendered mathematical preview.
- Validate input before solving.
- Show meaningful mathematical error messages.
- Prevent invalid or unsupported operations.

Buttons:
- Check Exactness
- Solve Equation
- Clear
- Load Example

## Exactness Detection

Compute:

∂M/∂y

and

∂N/∂x

Check whether:

∂M/∂y = ∂N/∂x

using SymPy symbolic simplification.

Do not use numerical equality as the primary exactness test.

Display:

- Original equation.
- Partial derivative of M with respect to y.
- Partial derivative of N with respect to x.
- Simplified derivative difference.
- Exactness classification.
- Explanation of the result.

For exact equations, continue to solve automatically.

For non-exact equations, examine the supported integrating-factor cases.

# 6. MODULE TWO — EXACT EQUATION SOLVER

For an exact equation:

M dx + N dy = 0

Find a potential function F(x,y) such that:

F_x = M

F_y = N

Mathematical procedure:

1. Integrate M with respect to x.
2. Introduce an unknown function g(y).
3. Differentiate the resulting expression with respect to y.
4. Compare with N.
5. Determine g'(y).
6. Integrate g'(y) to obtain g(y).
7. Construct F(x,y).
8. Present the final implicit solution F(x,y) = C.
9. Verify by differentiating F.

Show all intermediate expressions using readable mathematical notation.

Use actual SymPy expressions and transformations.

Never fabricate intermediate integration steps.

Handle integration failures or unsupported special-function results gracefully.

# 7. MODULE THREE — NON-EXACT EQUATION SOLVER

For a non-exact equation, support simple integrating-factor cases.

## Case A — Integrating Factor Depending on x

Calculate:

(M_y - N_x) / N

If the expression simplifies to a function of x alone, calculate:

μ(x) = exp(∫[(M_y - N_x)/N] dx)

Multiply M and N by μ(x).

Verify the transformed equation is exact.

Proceed with the exact equation solver.

## Case B — Integrating Factor Depending on y

Calculate:

(N_x - M_y) / M

If the expression simplifies to a function of y alone, calculate:

μ(y) = exp(∫[(N_x - M_y)/M] dy)

Multiply M and N by μ(y).

Verify exactness again.

Proceed with the exact equation solver.

For both cases:
- Check denominators and domain restrictions.
- Check genuine variable dependence through symbolic simplification and free-symbol analysis.
- Handle zero or undefined expressions carefully.
- Verify the resulting integrating factor rather than assuming correctness.
- Explain every mathematical step.

If neither supported method applies, show:

"This equation is not exact, and a supported simple integrating factor could not be identified."

Never claim that the equation has no solution.

Do not invent an unsupported integrating factor.

Clearly state which methods are supported.

## Model Comparison

For supported explicit or numerically evaluable ODE solution branches, calculate predicted values at the observed x-coordinates.

Display:

Observed y

Predicted y

Residual

Squared residual

Define:

Residual = observed_y - predicted_y

Calculate:

MSE = mean(residual²)

RMSE = sqrt(MSE)

MAE = mean(abs(residual))

R² = 1 - SSE/SST

Handle cases where SST=0 without producing misleading metrics.

## Parameter Fitting

For supported equation families, fit the integration constant C or initial-value parameter using least squares when valid and identifiable.

Use scipy.optimize.least_squares or scipy.optimize.curve_fit when appropriate.

Distinguish between:
- A theoretically predicted curve from a supplied initial condition.
- A curve calibrated against observed data.

Do not report a fitted parameter if no valid numerical solution or identifiable parameterization exists.

on y ≠ 0, up to a nonzero constant multiple on each connected interval.

y dx + x dy = 0

Final solution:

xy = C
