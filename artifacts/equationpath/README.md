# EquationPath

This application runs entirely in the browser. No backend or Python installation is required.

From the repository root:

```powershell
pnpm install
pnpm dev
```

Open http://localhost:5173. Use `pnpm build` and `pnpm preview` for the static production app.

See the [root README](../../README.md) for full setup, mathematical scope, CSV format, testing and limitations.
